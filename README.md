A one-image summary of Monday 23 November 2026's world news — 37 stories
in a flat-illustration serif broadsheet: 3 leads, 12 mediums, 22 briefs,
a map of the 15 drawn stories, and a DATE CHECK box.

## How it is built

`draw.py` renders `entry.png` (1024×1024, deterministic — the same bytes
on every run). `main.py` copies it to `/output/entry.png` after validating
the PNG signature and dimensions.
